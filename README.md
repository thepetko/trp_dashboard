# TRP Riadiace centrum

Interaktívny dashboard pre riadenie kampane Trauma rešpektujúceho prístupu.

Obsahuje:

- prioritné úlohy a ďalšie kroky,
- video knižnicu a odporúčané časové výrezy,
- publikačný kalendár,
- sledovanie KPI,
- odkazy na pracovné podklady.

Úpravy v dashboarde sa ukladajú lokálne v prehliadači používateľa. Zálohu je možné exportovať a neskôr obnoviť.
